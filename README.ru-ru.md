# LeetCode in Parens

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Common Lisp](https://img.shields.io/badge/Common%20Lisp-SBCL-3d6aa6.svg)

Все бесплатные задачи LeetCode из категории Algorithms, решённые на Common
Lisp. Одна задача — один файл, и часто несколько подходов — грубой силой,
оптимизированно, рекурсивно — рядом, в одном файле.

## Прогресс

| Сложность | Решено |
|---|---|
| 🟢 Easy (лёгкие) | 1 |
| 🟡 Medium (средние) | 0 |
| 🔴 Hard (сложные) | 0 |

Полный индекс — по номеру, сложности и теме — находится в
[PROBLEMS.md](PROBLEMS.md).

## Зачем несколько подходов к одной задаче

Решить задачу один раз — доказательство того, что вы нашли ответ. Решить её
ещё раз через грубую силу, ещё раз в оптимизированном варианте, ещё раз
рекурсивно (или любым другим возможным способом) — доказательство того, что
вы понимаете, *почему* ответ работает, и оставляет ориентир для того, как
одна и та же идея выглядит при разных ограничениях. Это не обязательное
требование для каждой задачи, но структура готова к этому всегда, когда это
того стоит.

## Структура репозитория

```
solutions/
  easy/
    two-sum.lisp
  medium/
  hard/
```

Задача — это один файл `.lisp`, названный собственным slug LeetCode (тем, что
в URL задачи) и лежащий прямо в папке той сложности, которую ему присвоил
LeetCode. Номера задачи в пути нет; slug — уникальный ключ. В каждом файле:

- комментарий-заголовок со ссылкой, сложностью, темами и подходами;
- собственный пакет `leetcode.<slug>` с явным списком экспорта;
- по одной функции на подход: функция с именем задачи — канонический подход,
  остальные получают суффикс, например `two-sum-brute-force`;
- примеры из условия внизу, в комментариях, с ожидаемыми результатами.

Веб-интерфейс GitHub обрезает папки, в которых больше 1000 элементов, а
`medium/` их превысит. Используйте [PROBLEMS.md](PROBLEMS.md) или нажмите `t`
на странице репозитория, чтобы найти задачу.

## Запуск локально

Требования: [SBCL](https://www.sbcl.org).

```bash
sbcl --load solutions/easy/two-sum.lisp
```

```lisp
(leetcode.two-sum:two-sum '(2 7 11 15) 9)
;; => (0 1)
```

## Как проверяются решения

CI и набора тестов нет. Перед отправкой решения автор загружает его в SBCL и
вручную вычисляет в REPL примеры из конца файла. Эти решения не оцениваются
судьёй LeetCode, поэтому больше их ничто не проверяет: issue о неверном ответе
приветствуется.

## Соглашения

- Common Lisp, разработка на SBCL.
- Один пакет на файл с явным `:export`; имена в `kebab-case`.
- У каждой экспортируемой функции есть docstring с отдельной строкой на
  каждый параметр.
- Ожидаемые сбои — это типы условий (`no-solution`), а не общие ошибки.
- Conventional Commits на английском, пуш прямо в `main`.

Полные правила — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Область и правовые вопросы

В область входят все бесплатные (не premium) задачи категории Algorithms на
LeetCode. Задачи по SQL, Bash, Pandas и JavaScript 30-day вне области.

Условия задач принадлежат LeetCode. Этот репозиторий ссылается на каждую
задачу и не копирует условия и тестовые данные сайта. Репозиторий не связан с
LeetCode.

## Участие в проекте

Это личная витрина, поэтому решения написаны самим автором. Исправления
приветствуются — неверный ответ, опечатка — через issue или pull request, см.
[CONTRIBUTING.md](CONTRIBUTING.md). Альтернативные решения от третьих лиц не
принимаются.
