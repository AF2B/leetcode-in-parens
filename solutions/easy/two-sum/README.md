# 1. Two Sum

[LeetCode problem 1](https://leetcode.com/problems/two-sum/)

- **Difficulty**: 🟢 easy
- **Topics**: array, hash-table
- **Approaches**: hash-map (canonical), brute-force

## Description

Given a list of integers `nums` and an integer `target`, return the indices
of the two numbers that add up to `target`. Exactly one solution exists, and
the same element cannot be used twice. The answer may be returned in any
order.

Constraints: `2 <= nums.length <= 10^4`, `-10^9 <= nums[i] <= 10^9`, and
`-10^9 <= target <= 10^9`.
